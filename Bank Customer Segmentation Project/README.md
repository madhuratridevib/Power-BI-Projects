# Bank Customer Segmentation – Power BI Project

## 📊 Project Overview
This project focuses on analysing bank customer data to segment customers based on transactional behaviour and engagement patterns.

## 🛠 Tools Used
- Power BI

## 📁 Project Files (Google Drive)
Due to GitHub file size limitations, the Power BI (.pbix) file and datasets are stored on Google Drive.

## 📌 Key Analysis & Insights
- Customer segmentation using RFM analysis
- Identification of high-value and low-value customers
- Actionable business insights for retention strategies
